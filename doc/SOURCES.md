# Datasheet dan referensi hardware

Dokumen lokal di folder ini merupakan referensi untuk profil NodeMCU ESP-12E, ESP32 DevKit, dan OLED SSD1306. Periksa revisi board/modul yang digunakan karena board klon dapat berbeda.

| File lokal | Referensi dan kegunaan |
|---|---|
| `NodeMCU-DevKit-v1.0-instruction.pdf` | [NodeMCU DevKit v1.0 Instruction](https://github.com/nodemcu/nodemcu-devkit-v1.0/blob/master/Documents/NODEMCU-DEVKIT-V1.0-INSTRUCTION-EN.pdf) — panduan board NodeMCU. |
| `ESP-12E-module-specification.pdf` | [Ai-Thinker ESP-12E Specification](https://aithinker-static.oss-cn-shenzhen.aliyuncs.com/docs/Public%20Document%20Center/WiFi/esp8266/Specification/ESP-12E%20Specification-20220807.pdf) — spesifikasi modul ESP-12E. |
| `ESP8266EX-datasheet.pdf` | [Espressif ESP8266EX Datasheet](https://www.espressif.com/sites/default/files/documentation/0a-esp8266ex_datasheet_en.pdf) — spesifikasi SoC ESP8266. |
| `ESP32-WROOM-32-datasheet.pdf` | [Espressif ESP32-WROOM-32 Datasheet](https://www.espressif.com/sites/default/files/documentation/esp32-wroom-32_datasheet_en.pdf) — spesifikasi modul ESP32-WROOM-32; pastikan varian modul pada board aktual. |
| `ESP32-DevKitC-v4-schematic.pdf` | [Espressif ESP32-DevKitC V4 schematic](https://dl.espressif.com/dl/schematics/esp32_devkitc_v4-sch.pdf) — skematik board resmi sebagai referensi, **bukan** skematik semua board/klon DevKit V1. |
| `SSD1306-controller-datasheet.pdf` | [SSD1306 Datasheet mirror](https://cdn-shop.adafruit.com/datasheets/SSD1306.pdf) — controller OLED SSD1306; karakteristik modul display tetap bergantung pada modul yang dipakai. |

Panduan web resmi untuk board referensi ESP32: [ESP32-DevKitC V4 User Guide](https://docs.espressif.com/projects/esp-dev-kits/en/latest/esp32/esp32-devkitc/user_guide.html).
